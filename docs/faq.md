# FAQ

## Video Counts

### How are video counts calculated?
Video counts are determined by the number of unique views on each video. Each view is counted only once per user per video within a 24-hour period.

### Why do my video counts seem inaccurate?
Video counts may appear inaccurate due to:
- **Caching**: Counts may not update in real-time due to caching mechanisms.
- **User Privacy Settings**: Users with certain privacy settings may not be tracked.

## Data Safety

### Is my data safe with Resensa?
Yes, Resensa prioritizes user data safety. We implement the following measures:
- **Encryption**: All data is encrypted both in transit and at rest.
- **Access Controls**: Strict access controls are in place to limit data access to authorized personnel only.

### How is my personal information used?
Your personal information is used solely for:
- Enhancing user experience
- Providing personalized content
- Communicating important updates

We do not sell or share your personal information with third parties without your consent.

## MCP Server Details

### What is the MCP server?
The MCP (Media Control Protocol) server is responsible for managing video streaming and user interactions in real-time.

### How can I check the status of the MCP server?
You can check the status of the MCP server by visiting our [status page](#). This page provides real-time updates on server performance and any ongoing issues.

### What should I do if the MCP server is down?
If the MCP server is down, please:
1. Check our [status page](#) for updates.
2. Contact our support team if the issue persists for more than 30 minutes.
