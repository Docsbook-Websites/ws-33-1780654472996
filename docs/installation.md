# Installation

Follow these simple steps to install and use Resensa in your browser. Resensa supports multiple browsers and requires minimal permissions for a seamless experience.

## Supported Browsers

Resensa can be installed on the following browsers:

- Google Chrome
- Microsoft Edge
- Brave
- Opera

## Installation Steps

### For Google Chrome

1. Open the [Chrome Web Store](https://chrome.google.com/webstore).
2. Search for "Resensa".
3. Click on the **Add to Chrome** button.
4. Confirm by clicking **Add extension** in the pop-up dialog.

### For Microsoft Edge

1. Open the [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/Microsoft-Edge-Extensions-Home).
2. Search for "Resensa".
3. Click on the **Get** button.
4. Confirm by clicking **Add extension** in the pop-up dialog.

### For Brave

1. Open the [Chrome Web Store](https://chrome.google.com/webstore) in your Brave browser.
2. Search for "Resensa".
3. Click on the **Add to Chrome** button.
4. Confirm by clicking **Add extension** in the pop-up dialog.

### For Opera

1. Open the [Opera Add-ons](https://addons.opera.com/en/extensions/).
2. Search for "Resensa".
3. Click on the **Add to Opera** button.
4. Confirm by clicking **Install** in the pop-up dialog.

## Permissions

Resensa requires minimal permissions to function effectively. During installation, you will be prompted to allow the following permissions:

- Access to your browser tabs
- Read and change your data on the websites you visit

## Getting Started

Once installed, you can start using Resensa immediately. Look for the Resensa icon in your browser's toolbar to access its features.

For further assistance, please refer to the [User Guide](#) or contact support.
